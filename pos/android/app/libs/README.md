# Библиотеки оборудования

Сюда кладутся библиотеки производителей, которые нельзя хранить в открытом репозитории.
После добавления файлов пересоберите APK (`npm run build:android -w pos`, затем `./gradlew assembleDebug`).

## ККТ АТОЛ — «Драйвер ККТ 10» для Android

1. Скачайте драйвер с сайта АТОЛ: https://fs.atol.ru → «Драйвер ККТ v.10» → архив для Android.
2. Возьмите из архива библиотеку `fptr10.aar` (или `libfptr10.jar` и папку `jniLibs` с `.so`-файлами).
3. Положите `.aar`/`.jar` в эту папку, `jniLibs` — в `pos/android/app/src/main/jniLibs`.

Касса обращается к классам `ru.atol.drivers10.fptr.Fptr` / `IFptr` драйвера (см. `AtolPlugin.java`).

Без драйвера можно работать через «Веб-сервер ДТО»: он входит в тот же пакет драйвера для Windows/Linux,
ставится на компьютер или мини-ПК в точке, к которому подключена ККТ. В кассе выберите «Веб-сервер ДТО».

## Терминал Сбербанка (интегрированный пин-пад)

Сбербанк выдаёт интеграционный пакет для Android вместе с договором эквайринга (через персонального менеджера
или техподдержку эквайринга). После получения пакета реализуется плагин `SberAcquiring` с методами
`pay({ amount })` и `refund({ amount, rrn })` (сумма в копейках) — интерфейс уже ожидается кассой
(`pos/src/acquiring.ts`). До этого используйте режим «Отдельный терминал».
