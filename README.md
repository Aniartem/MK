# MK — касса и бэк-офис для сети точек

Система из трёх частей, работающих с одной базой:

| Часть | Папка | Для кого |
|---|---|---|
| **Сервер (API)** | `server/` | Node.js + Fastify + PostgreSQL. Хранит чеки, товары, сотрудников, считает отчёты |
| **Бэк-офис** | `admin/` | Владелец и управляющие, в браузере. Рабочий стол, журнал документов, бюджет, отчёты, номенклатура, сотрудники, контрагенты, акции, план продаж |
| **Касса** | `pos/` | Кассиры, на Android-планшете. Продажа, возврат, наличные/карта, смены, списание |

## Что умеет

**Рабочий стол** — выручка без возвратов, количество и средний чек, сумма выпуска, потери; график по часам или дням
вместе со средним значением за те же дни четырёх прошлых недель; таблица по точкам: % от среднего, SKU, остаток,
отправлено/принято, план, прогноз на конец дня и % выполнения плана. Отдельные вкладки по товарам, сотрудникам,
способам оплаты и категориям. Фильтр по датам и адресам; быстрые кнопки «Вчера / Сегодня / Месяц».

**Журнал документов** — все документы в одном списке: чеки, выпуск, списания, перемещения, поступления от
поставщиков (накладные), инвентаризации, открытие/закрытие смен, внесения и изъятия наличных. Отсюда же
создаются складские документы. Выгрузка в Excel (CSV).

**Бюджет** — план и факт доходов и расходов по статьям (выручка с касс подтягивается сама), себестоимость
продаж/выпуска/списаний, расхождения инвентаризаций, прибыль по точкам.

**Отчёты** — продажи по товарам, категориям, точкам, дням, часам, сотрудникам и оплатам со сравнением с прошлым
днём/неделей/месяцем/годом; производство (выпуск против продаж и списаний); остатки на складе; движение товара
(остаток на начало → приход/расход → остаток на конец); часовые остатки по точкам; потери; ABC-анализ по выручке
и прибыли. Сотрудники: выручка, средний чек и расхождения кассы по сменам.

**Номенклатура** делится на товары (перепродажа), продукцию (своё производство) и сырьё. Себестоимость товара
обновляется из цены закупки в поступлении. **Акции**: автоматические (например, −30% на выпечку после 19:00) и
ручные, которые кассир выбирает на чек.

**Касса** — вход кассира по PIN из 4 цифр; открытие смены с остатком наличных; плитки товаров по категориям, поиск,
сканер штрихкодов; скидки по акциям; внесение и изъятие наличных; оплата картой или наличными с расчётом сдачи; режим возврата; списание; закрытие смены с
X-отчётом (сколько должно быть в кассе). **Работает без интернета**: каталог хранится на планшете, чеки копятся
в очереди и отправляются на сервер, когда появится связь. Повторная отправка не создаёт дублей.

## ⚠️ Фискализация (54-ФЗ)

Чтобы законно принимать оплату, каждый чек должен пройти через онлайн-кассу (ККТ с фискальным накопителем) и
уйти в ОФД. Сейчас касса работает в **тестовом режиме без ККТ** — подключение сделано через одну точку
(`pos/src/fiscal.ts`). Варианты подключения:

- **ККТ рядом с планшетом** (АТОЛ, Штрих-М) по USB/Bluetooth — нативный плагин на драйвере производителя;
- **облачная касса** (АТОЛ Онлайн, OrangeData и др.) — сервер отправляет чек по API, железо на точке не нужно.

Также понадобится эквайринг для оплаты картой (терминал банка или интеграция с ним).

## Запуск для разработки

Нужны Node.js 22 и PostgreSQL 16.

```bash
npm install
createdb mk                    # база по умолчанию: postgres://mk:mk@localhost:5432/mk
npm run seed -w server         # демо-данные: 3 пекарни, склад, ~10 недель продаж
npm run dev:server             # API на :3000
npm run dev:admin              # бэк-офис на http://localhost:5173
npm run dev:pos                # касса на http://localhost:5174/pos/
```

Демо-вход в бэк-офис: `admin@mk.local` / `admin123`. PIN кассиров: `1111`, `2222`, `3333`, `4444`.

Тесты сервера (нужна пустая база `mk_test`): `npm test`.

## Развёртывание на VPS

Подойдёт любой VPS с Docker (1–2 ГБ памяти достаточно на старте) и домен, направленный на его IP.

```bash
git clone https://github.com/Aniartem/MK.git && cd MK
cp .env.example .env           # впишите DOMAIN, DB_PASSWORD, JWT_SECRET (openssl rand -hex 32)
docker compose up -d --build
docker compose exec app node server/dist/create-owner.js you@mail.ru 'надёжный-пароль' 'Ваше имя'
```

После этого бэк-офис открывается на `https://ваш-домен/`, касса — на `https://ваш-домен/pos/`.
HTTPS-сертификат выпускается автоматически. Резервная копия базы:
`docker compose exec db pg_dump -U mk mk > backup.sql`.

## Касса на Android-планшете

APK собирается автоматически в GitHub Actions (workflow **Android APK**) — скачайте `mk-pos-apk` из раздела
Artifacts последнего запуска и установите на планшет. При первом запуске укажите адрес сервера и выберите точку.

Собрать вручную (нужен Android Studio):

```bash
npm run build:android -w pos
cd pos/android && ./gradlew assembleDebug
```

## Устройство

- `server/migrations/` — схема БД (применяется автоматически при старте).
- Чеки и смены получают id на планшете; сервер сам пересчитывает суммы по позициям.
- Права: владелец и управляющие — бэк-офис; кассир — только касса и списание по своей точке.
- Часовой пояс точек задаётся `APP_TZ` (по умолчанию `Europe/Samara`, UTC+4) — от него зависят часы на графике и границы дня.
- Остатки считаются из движений: выпуск + поступления + перемещения ± инвентаризации − списания − продажи + возвраты.
